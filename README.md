# Hi! I'm David Vacaroiu

I'm an Electronics and Technical Informatics student at **HTBLuVA Salzburg**, working at the intersection of custom PCB hardware, embedded firmware, and systems programming in multiple languages. I enjoy building things from scratch, both PCBs and software.
